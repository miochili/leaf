# Download Leaf for Windows

GitHub allows files up to 100 MB, so the 108 MB installer is split into four parts.

1. Download all five files in this folder (`Join Leaf Setup.bat` and `Leaf-Setup.part0` to `part3`) into the same folder on your PC.
2. Double-click **Join Leaf Setup.bat**. It rebuilds `Leaf-Setup.exe` and starts the installer.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. Leaf isn't code-signed.

No admin rights are needed.
